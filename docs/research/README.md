# Research behind the factory packs

These briefs were written before the presets: each one collects what is publicly documented about a
sound (interviews, credits, rig rundowns, gear specs), separates it from inference, translates it into
measurable terms, and proposes WARMFUL recipes. The artists did not take part in this and do not
endorse the plug-in.

The recipes are drafts. The shipped presets in [`source/dsp/FactoryPresets.cpp`](../../source/dsp/FactoryPresets.cpp)
were picked from them, merged where two briefs proposed the same idea, renamed, level-matched to the dry
signal, and checked by rendering (pitch ratios, gate rate and depth, echo times, reverb tails).
Knob values in the briefs can therefore differ from the shipped ones; [`../PRESETS.md`](../PRESETS.md) is
the reference for those.
