# WARMFUL factory presets

Generated by `warmful_render presets-md > docs/PRESETS.md` from `source/dsp/FactoryPresets.cpp`.

All presets assume **MEDIUM** calibration and MIX at 100 %. Values are pot positions in % and as a
clock face (7:00 = fully left, 12:00 = centre, 5:00 = fully right), so they can also be dialled on a
physical pedal; the plug-in is a behavioural model, so expect to fine-tune by ear there.
Secondary controls are set in the SECONDARY menu (A+B); routing in FX SETUP (A+D).
